Comandos SQL na Prática

Selecione uma categoria no menu acima para explorar os exemplos de sintaxe.

Comandos com SELECT

Tabela: Alunos & Cursos

  • Mostrar o nome e o CPF dos alunos (juntos):
    SELECT concat(cpf, nome) FROM aluno;
  • Mostrar o nome e o telefone com espaço entre os dados:
    SELECT concat(nome, ' ', telefone) AS Dados_contato FROM aluno;
  • Mostrar os nomes dos alunos com apenas as 5 primeiras letras:
    SELECT substr(nome, 1, 5) FROM aluno;
  • Medir a quantidade de caracteres do nome:
    SELECT length(nome) FROM aluno;
  • Trocar valores vazios (NULL) por um texto padrão:
    SELECT COALESCE(codigo_dpto, 'Não informado') FROM curso;

Tabela: Professores (Agregação e Datas)

  • Calcular a média de salário dos professores:
    SELECT avg(salario) FROM professor;
  • Somar todos os salários dos professores:
    SELECT sum(salario) FROM professor;
  • Mostrar o maior salário:
    SELECT max(salario) FROM professor;
  • Mostrar o menor salário:
    SELECT min(salario) FROM professor;
  • Formatar a data para dia, mês e ano (DD/MM/AA):
    SELECT date_format(data_contratacao, '%d/%m/%y') FROM professor;
  • Extrair apenas o ano de contratação:
    SELECT extract(year FROM data_contratacao) FROM professor;

Funções de Data e Hora do Servidor

  • Retorna a data atual do servidor:
    SELECT CURDATE();
  • Retorna o horário atual do sistema:
    SELECT CURTIME();
  • Retorna a data e a hora atuais do servidor:
    SELECT SYSDATE();

Exemplos de DELETE

Tabela: Produto

  • Remover o produto 'Webcam Full HD':
    DELETE FROM tbproduto WHERE NomeProduto = 'Webcam Full HD';
  • Excluir um produto pelo código 3:
    DELETE FROM tbproduto WHERE Codigo = 3;
  • Excluir todos os produtos com preço acima de R$ 3.000:
    DELETE FROM tbproduto WHERE Preco > 3000;

Tabela: Vendas

  • Excluir a venda de código 5:
    DELETE FROM tbvenda WHERE Codigo = 5;
  • Deletar todas as vendas do Cliente 1:
    DELETE FROM tbvenda WHERE CodigoCliente = 1;
  • Remover vendas com valor total abaixo de 200:
    DELETE FROM tbvenda WHERE ValorTotal < 200;
  • Remover a venda feita em 10/08/2024:
    DELETE FROM tbvenda WHERE DataVenda = '2024-08-10';

Tabela: Funcionários

  • Remover o funcionário 'Ricardo Almeida':
    DELETE FROM tbfuncionario WHERE NomeFuncionario = 'Ricardo Almeida';

Exemplos de UPDATE

Tabela: Produtos

  1. Aumentar o preço do Notebook em 10%:
    UPDATE tbproduto SET preco = preco * 1.10 WHERE NomeProduto = 'Notebook';
  2. Atualizar a quantidade em estoque do Mouse Gamer para 60:
    UPDATE tbproduto SET Quantidade = 60 WHERE NomeProduto = 'Mouse Gamer';
  3. Alterar o nome do produto 'SSD 1TB' para 'SSD NVMe 1TB':
    UPDATE tbproduto SET NomeProduto = 'SSD NVMe 1TB' WHERE NomeProduto = 'SSD 1TB';
  4. Dobrar a quantidade de impressoras em estoque:
    UPDATE tbproduto SET Quantidade = Quantidade * 2 WHERE NomeProduto = 'Impressora';

Tabela: Funcionários

  1. Promover Maria Oliveira para o cargo de Supervisora:
    UPDATE tbfuncionario SET Cargo = 'Supervisora' WHERE NomeFuncionario = 'Maria Oliveira';
  2. Atualizar o salário de Felipe Costa para R$ 9.000,00:
    UPDATE tbfuncionario SET Salario = 9000.00 WHERE NomeFuncionario = 'Felipe Costa';

Tabela: Vendas

  1. Aumentar em 10% o valor de todas as vendas anteriores a 01/03/2024:
    UPDATE tbvenda SET ValorTotal = ValorTotal * 1.10 WHERE DataVenda < '2024-03-01';

Exemplos de SHOW e DESC

  • Mostrar todos os Bancos de Dados disponíveis:
    SHOW DATABASES;
  • Mostrar todas as tabelas do Banco de Dados selecionado:
    SHOW TABLES;
  • Exibir a estrutura/descrição das colunas da tabela aluno:
    DESC aluno; -- ou SHOW COLUMNS FROM aluno;

Exemplos de ALTER TABLE

  • Inserir uma nova coluna (email) na tabela aluno:
    ALTER TABLE aluno ADD email VARCHAR(255);
  • Excluir a coluna telefone da tabela professor:
    ALTER TABLE professor DROP COLUMN telefone;
  • Renomear a tabela departamento para dpto:
    ALTER TABLE departamento RENAME TO dpto;
  • Alterar o nome da coluna endereco para endereco_residencial:
    ALTER TABLE aluno CHANGE endereco endereco_residencial VARCHAR(255);
  • Definir a coluna nome como obrigatória (NOT NULL):
    ALTER TABLE professor MODIFY nome VARCHAR(255) NOT NULL;
  • Adicionar uma chave primária em uma tabela existente:
    ALTER TABLE disciplina ADD PRIMARY KEY(codigo);
  • Remover a chave primária da tabela:
    ALTER TABLE disciplina DROP PRIMARY KEY;
  • Modificar a posição da coluna telefone para aparecer logo após o nome:
    ALTER TABLE aluno MODIFY telefone VARCHAR(25) AFTER nome;
  • Adicionar auto-incremento na chave matrícula:
    ALTER TABLE professor MODIFY matricula INT AUTO_INCREMENT;
